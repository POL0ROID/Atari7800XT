# Atari7800XT

https://youtu.be/LSctGXLyQ7Q

This project currently contains a fork of [test7800](https://github.com/jetsetilly/test7800) by JetSetIlly, which is licensed under the GNU General Public License v3.0. For usage information, see his page:

To see the Maria v1.01 latch fix for Karateka and Super Huey UH-IX in action, compile the emulator with go build, open the command line from the file directory, and use `test7800.exe -karateka=TRUE -run "directory of ROM file here"`.

This project is assisted by consultation with Gemini for historical and technological research, as well as understanding the existing codebase (I was not familiar with Go at the start), troubleshooting, and evaluation of general approaches (getting a second opinion on if things would work the way I envisioned). All code is hand-written.
